## About Us

NEXORA is an open-source organization that builds fun, fast and creative web apps and games for the youth generation. We focus on projects that:

- run directly in the browser, with no sign-up needed
- work well on both phones and computers
- respect your privacy and keep your data on your device
- are free and open source for everyone to learn from and build on

## Getting Started

Every project has its own README with instructions. In short:

1. Open the project's **Live** link to use it right away, or
2. Open the **Repository** link and follow the setup steps in its README.

## Contributing

We welcome contributions of any size.

1. Fork the repository you want to improve.
2. Create a branch for your change.
3. Commit your work and open a pull request.

Found a bug or have an idea? Open an **Issue** in that project's repository.
